# Warren County, PA — Child Care / Family Support: Pilot List

**County:** Warren County, Pennsylvania (rural, northwestern PA; county seat Warren, PA; other towns: Youngsville, Sheffield, Tidioute, Russell, Sugar Grove, Bear Lake, North Warren, Starbrick, Clarendon).
**Category:** Child care / family support.
**Date built:** 2026-11-08.
**Directory:** Statewide PA 211 (search.pa211.org / pa211.org) is the directory for Pennsylvania.
**Auditor:** Keith Conklin, with AI assistance from Muse. Keith is NOT a local resident of Warren County.
**Status:** Pilot list only. Nothing in this audit has been sent to PA 211 or to any organisation. No organisation was contacted.

## Method and limits — please read before using this

- PA 211's search pages are JavaScript-driven, and a text fetch on 2026-11-08 did not return a complete, extractable Warren County-filtered child-care result list. Two PA 211 items were retrieved directly in text (Warren County Children's Advocacy Center; Domestic Relations of Warren County), plus a PA 211 item for Forest-Warren Human Services / Children's Protective Services. The pilot is therefore a **partial pilot anchored on those retrievable PA 211 items + secondary lists (county government pages, the Forest-Warren Family Resource Hub, Head Start directories) + organisations' own sites**, NOT a complete county directory. A live-browser check of search.pa211.org for Warren County child care is still outstanding before any send to PA 211.
- ZIP code does NOT settle county. Exact-address geocoding does. Several Warren ZIP codes spill into neighbouring counties, and neighbouring-county providers (Forest County, Erie County, New York) appear in Warren searches. Out-of-scope items are listed at the end and excluded from the verdict counts.
- Own site beats directory; directory beats aggregator. Public web only — no organisation was contacted.
- Never publish children's personal information or photos. None is included here.
- This audit was prepared with AI assistance. Corrections, challenges and updates from statewide PA 211 or the organisations themselves are welcome — that is the point of staging it here first.
