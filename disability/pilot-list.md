# Warren County, PA — Disability Services: Pilot List

**Checked: 2026-11-08. Status: pilot list only — nothing has been sent.**
**Auditor: Keith Conklin. Keith is NOT a local resident of Warren County.**
**Directory anchor: statewide PA 211 (search.pa211.org / pa211.org).**

This is a partial pilot, NOT a complete county directory. PA 211's search
pages are JavaScript-driven and a text fetch on 2026-11-08 did not return a
complete Warren County-filtered disability list. The pilot below is therefore
anchored on retrievable PA 211 items plus the Forest Warren Human Services
Family Resource Hub "Disability & ODP" section (12 listings), the Inglis
Warren County Quick Start guide (Feb 2025 / Jun 2026 versions), the Warren
County Resource Guide (Sep 2019, used only as a lead list, never as evidence),
and organisations' own sites. A live-browser check of search.pa211.org for
Warren County disability listings is still outstanding before any send.

Each entry gives the directory / secondary-list claim as found, before
checking. Verdicts are in `audit-report-2026-11-08.md`. Own site beats
directory; directory beats aggregator. Public web only — no organisation
was contacted.
